## Featured Projects

### [Enterprise Cybersecurity Lab](https://github.com/ChadiBlal/Enterprise-Cybersecurity-Lab)

An enterprise-style virtualized laboratory designed to study security architecture, monitoring, detection, and infrastructure hardening. The environment includes Ubuntu, Windows, Wazuh, Suricata, OpenLDAP, OpenVPN, Apache, SQL, DNS, SSH, SMB, and monitoring workflows.

### [Secure TCP Chat Server in C](https://github.com/ChadiBlal/TCP-Chat-Server-in-C-language)

A multi-client terminal chat application developed in C using TCP sockets and `select()`. The project explores client-server communication, concurrent connections, and AES-256-CBC encryption for protecting message contents.

### [Educational Worm PFE](https://github.com/ChadiBlal/EducationalWormpfe)

A final-year project focused on malware behavior, worm propagation concepts, network analysis, and defensive detection. The work was conducted for educational and research purposes in a controlled laboratory environment.
